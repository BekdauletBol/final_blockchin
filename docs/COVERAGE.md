## How to Generate

```bash
# From project root, after installing deps:
forge coverage \
  --no-match-contract "Fork" \
  --report lcov \
  --report summary \
  | tee docs/COVERAGE.md

# To view HTML report:
genhtml lcov.info --output-directory coverage-html
open coverage-html/index.html
```
